# Custom Components Library

## 🚀 About the Project
**Custom Components Library** is a lightweight, flexible UI component library designed to simplify development and enhance styling, similar to **MUI** or **Chakra UI**.

---

## 🔧 Tech Stack
This project is powered by a modern technology stack:

### 🖥 Core Technologies
- **React 18**
- **TypeScript**
- **Webpack**

### 🎨 UI & Styling
- **SCSS**
- **CSS Modules**

### 🛠 Development & Tooling
- **Storybook** (Component Documentation)
- **Jest & Testing Library** (Unit Testing)
- **ESLint & Prettier** (Code Formatting & Linting)
- **Husky & Lint-Staged** (Git Hooks & Code Quality)

---

## 📦 Installation & Usage

```bash
# Install dependencies
npm install

# Build the library
npm run build

# Link the package in another project
npm link custom-components-lib

# OR publish the package to npm
npm publish custom-components-lib
```
